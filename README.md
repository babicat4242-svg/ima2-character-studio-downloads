# HERA 캐릭터 · HERA Character

[Windows 설치 파일 다운로드](https://github.com/babicat4242-svg/ima2-character-studio-downloads/releases/latest)

Windows 10/11 64비트용 캐릭터 시트 앱입니다.

1. `HERA-Character-0.1.7-Setup.exe`를 실행해 설치합니다. 기존 앱은 생성 작업을 마친 뒤 종료하세요.
2. 바탕 화면의 HERA 캐릭터를 열고 **Sign in with ChatGPT**로 본인 계정을 연결합니다. 별도 API 키는 필요하지 않습니다.
3. 같은 인물의 선명한 원본 사진을 1~3장 선택합니다. 생성된 캐릭터 시트를 재사용하면 원래 피부 디테일이 이미 바뀌었을 수 있으므로 원본 사진을 권장합니다.
4. 시트 구성, 체형, 의상 핏을 고르고 **Generate sheet**를 누릅니다.
5. 결과는 보관함에 자동 저장됩니다. **View full size**로 원본 크기를 확인하고 **Save image**로 PNG를 저장할 수 있습니다.

## 구성과 체형

- **A · Outfit:** 얼굴 3컷 + 옷을 입은 전신 4컷. 원본 의상을 유지하도록 요청합니다.
- **B · Higgsfield:** 정면 목 아래 의상, 후면 전신, 얼굴·상반신의 3컷 구성입니다.
- **C · Body reference:** 얼굴 3컷 + 전신 4컷. 불투명한 흰색 나시와 짧은 피트 레깅스, 맨발을 사용합니다.
- **From photo:** 사진에 보이는 체형을 유지합니다. 얼굴만 보이면 자연스러운 기본 체형을 사용하며, 원하는 체형은 Extra instructions에 적을 수 있습니다.
- **Model / Idol:** 각각 등록된 체형 비율을 요청합니다. 앱에 포함된 참조는 얼굴이 가려진 흑백 체형 기준이며, 사용자 사진이 얼굴·머리·피부의 기준입니다. 정확한 비율은 생성 결과에서 확인하세요.

## 화질과 모델

생성은 ChatGPT 로그인에 연결된 Codex 내장 도구만 사용합니다. 사용 가능 계정과 Codex 사용 한도가 필요합니다. 앱에서 GPT Image 2.6이나 정확한 4K 출력을 고정할 수 있다고 보장하지 않습니다.

화면 상단 숫자는 실제 출력 크기입니다. 테스트 출력은 1672×941이었습니다. 저장 시 결과를 강제로 확대하거나 패널별로 재배치하지 않습니다. **View full size**는 화질 보정이 아니라 원본 픽셀 크기로 보는 기능입니다.

새로 선택한 원본 파일의 내용과 색상 프로필을 보존해 전달합니다. 이전 버전에서 이미 사라진 디테일이나 색상 프로필은 자동 복원할 수 없으므로 원본 파일을 다시 선택하세요.

## 저장과 개인정보

업데이트 후에도 기존 보관함과 로그인 위치를 유지합니다. 기존 결과는 자동 재생성하지 않습니다.

사진과 보관함은 이 컴퓨터의 앱 데이터에 저장됩니다. 생성 시 선택한 참조 사진·체형 기준·요청이 OpenAI로 전달됩니다. 별도 HERA 서버로 사진을 보내거나 다른 컴퓨터와 자동 동기화하지 않습니다.

이 앱은 독립 제작 앱이며 OpenAI 공식 앱이 아닙니다. Windows 설치 파일에는 코드 서명이 없습니다.

`SHA256SUMS.txt`에 적힌 SHA-256과 다운로드한 설치 파일의 해시를 비교해 파일 무결성을 확인할 수 있습니다.
